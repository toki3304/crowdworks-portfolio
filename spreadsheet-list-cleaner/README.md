# 申込リスト整理ツール（Excel / CSV / Googleスプレッドシート対応）

イベントやサービスの **申込一覧の表** を読み込み、
表記ゆれの整形・重複の削除・入力ミスの洗い出し・集計を自動で行うPythonツールです。

「フォームから集まった申込をスプレッドシートで目で見て直している」
「同じ人が2回申し込んでいないか毎回探している」といった作業を自動化します。

- **ふだんはパソコン内のExcel / CSV** で動きます（Googleの設定は不要）
- 設定をすれば、**Googleスプレッドシートを直接読み書き** することもできます

## できること

- 表記ゆれをそろえる
  - 全角の英数字（`ＡＢＣ１２３`）→ 半角、半角カナ（`ｱﾍﾞ`）→ 全角
  - 名前の前後や途中の余計な空白（全角スペースも）
  - メールアドレスを小文字にそろえる（`Taro@EXAMPLE.com` → `taro@example.com`）
  - 電話番号をハイフン区切りにそろえる（`09011110002` → `090-1111-0002`）
  - 日付の書き方をそろえる（`2026/8/3`・`2026年8月3日` → `2026-08-03`）
  - 人数の「名」「人」を取り除いて数値にする（`２名` → `2`）
- **重複の削除**：同じメールアドレスの申込は最初の1件だけを残し、取り除いた行は別シートに記録
- **要確認の洗い出し**：日付が読めない、メールアドレスの形式がおかしい、電話番号の桁数が違う、などの行に理由をつけて一覧にする
- **集計**：プラン別・月別の申込件数と人数の合計（要確認の行は集計に含めません）
- 結果は5つのシートに出力し、**元のデータは書き換えません**
  - 整形済み ／ 重複 ／ 要確認 ／ プラン別集計 ／ 月別集計
- どの行が元の表の何行目だったか分かるように「元の行」の列をつける
- エラーは日本語で表示（必要な列がない、ファイルがない、出力ファイルをExcelで開いたまま、シート名が違う、など）

## 入力の形式

1行目に次の列名がある表を想定しています（列の順番は自由、ほかの列があっても問題ありません）。

| 申込日 | 氏名 | メールアドレス | 電話番号 | プラン | 人数 |
|---|---|---|---|---|---|
| 2026/08/01 | 山田 太郎 | taro.yamada@example.com | 090-1111-0001 | スタンダード | 2 |
| 2026年8月3日 | 鈴木 一郎 | ICHIRO.SUZUKI@EXAMPLE.COM | ０９０－１１１１－０００３ | スタンダード | ３ |

`sample_data/申込一覧.csv` に、わざと表記ゆれ・重複・入力ミスを混ぜた30件のダミーデータが入っています
（名前・メールアドレス・電話番号はすべて架空のものです）。

## 実行方法

### 1. 準備（最初の1回だけ）

1. [Python公式サイト](https://www.python.org/downloads/) からPython 3.10以上をインストールします
   （Windowsではインストール画面の **「Add python.exe to PATH」にチェック** を入れてください）
2. このフォルダでコマンドプロンプト（Macはターミナル）を開き、必要なライブラリを入れます

```
pip install -r requirements.txt
```

> フォルダでコマンドプロンプトを開くには、エクスプローラーでこのフォルダを開き、
> 上のアドレスバーに `cmd` と入力して Enter を押します。

### 2. 実行（Excel / CSV）

```
python clean_list.py
```

`sample_data/申込一覧.csv` が整理され、`output/申込一覧_整理済み.xlsx` ができます。

自分のファイルを整理したいときは、入力ファイルと出力ファイルを指定します。

```
python clean_list.py 入力ファイル.xlsx 出力ファイル.xlsx
```

## Googleスプレッドシートで使う（任意）

Googleスプレッドシートの「申込一覧」シートを読み込み、
同じスプレッドシートに「整形済み」「重複」などのシートを追加して結果を書き込みます。
元の「申込一覧」シートは書き換えません。

### 1. 鍵ファイル（credentials.json）を用意する（最初の1回だけ）

1. [Google Cloud コンソール](https://console.cloud.google.com/) にGoogleアカウントでログインし、新しいプロジェクトを作ります
2. 「APIとサービス」→「ライブラリ」で **Google Sheets API** と **Google Drive API** を検索し、それぞれ「有効にする」を押します
3. 「APIとサービス」→「認証情報」→「認証情報を作成」→ **サービスアカウント** を選び、名前を入れて作成します
4. 作成したサービスアカウントを開き、「キー」タブ →「鍵を追加」→「新しい鍵を作成」→ **JSON** を選びます
5. ダウンロードされたファイルの名前を `credentials.json` に変えて、このフォルダ（`clean_list.py` と同じ場所）に置きます

> **注意：`credentials.json` はパスワードと同じです。GitHubに上げたり、人に送ったりしないでください。**
> このフォルダの `.gitignore` で、Gitに入らないようにしてあります。
> 別の場所に置きたいときは、環境変数 `GOOGLE_CREDENTIALS` に場所を指定するか、`--credentials` オプションで指定します。

### 2. スプレッドシートを共有する

1. `credentials.json` をメモ帳で開き、`"client_email"` に書かれたメールアドレス（`〜@〜.iam.gserviceaccount.com`）をコピーします
2. 対象のGoogleスプレッドシートを開き、右上の「共有」からそのメールアドレスを **編集者** として追加します
3. 入力の表があるシートの名前を「申込一覧」にします（別の名前のときは `--worksheet` で指定します）

### 3. 実行

スプレッドシートのURLの `/d/` と `/edit` の間の文字列が **スプレッドシートID** です。

```
https://docs.google.com/spreadsheets/d/【ここがID】/edit
```

```
python clean_list.py --google --sheet-id スプレッドシートID
python clean_list.py --google --sheet-id スプレッドシートID --worksheet "フォームの回答 1"
```

実行後、スプレッドシートに「整形済み」「重複」「要確認」「プラン別集計」「月別集計」のシートが追加されます
（2回目以降は同じシートの中身を書き直します）。

## テスト

```
python -m pytest
```

整形・重複削除・要確認の判定・集計・Excel出力・エラー表示を確認します。
Googleスプレッドシートのテストは、本物のGoogleには接続せず、同じ動きをするテスト用の部品で確認します。

## ファイル構成

```
spreadsheet-list-cleaner/
├── clean_list.py         # ツール本体（整形・重複削除・集計、Excel/CSVの読み書き）
├── google_sheets.py      # Googleスプレッドシートの読み書き（--google のときだけ使う）

├── sample_data/
│   └── 申込一覧.csv       # ダミーデータ
└── tests/
    └── test_clean_list.py  # 自動テスト
```

## カスタマイズの例

ご依頼に合わせて、次のような変更が可能です。

- 列名・チェック内容の変更（郵便番号や住所の表記ゆれ、必須項目の追加など）
- 重複の判定方法の変更（メールアドレスではなく「氏名＋電話番号」で判定、最新の申込を残す、など）
- Googleフォームの回答シートを毎日自動で整理
- 集計結果をグラフ付きで出力、別のスプレッドシートへ転記

## 使用技術

Python 3 / pandas / openpyxl / gspread（Google Sheets API）/ pytest
