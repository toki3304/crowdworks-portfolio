# crowdworks-portfolio

Pythonによる業務自動化ツールのポートフォリオです。

| ツール | 内容 |
|---|---|
| [売上Excel集計ツール](excel-sales-aggregator/) | 複数の売上Excel / CSVを1つにまとめ、月別×店舗別・商品別の集計表をExcelで出力 |
| [書籍情報スクレイピングツール](book-price-scraper/) | Webサイトの一覧ページを複数ページたどって商品名・価格・評価・在庫を取得し、CSV / Excelで出力 |
| [申込リスト整理ツール](spreadsheet-list-cleaner/) | 申込一覧（Excel / CSV / Googleスプレッドシート）の表記ゆれを整え、重複削除・入力ミスの洗い出し・プラン別／月別集計を自動で行う |

## 案件用ひな形

[project-template](project-template/) は、受注した案件を毎回同じ手順で進めるためのひな形です。
要件メモ・Claude Code向けの約束事（CLAUDE.md）・ツール本体とテストの骨組み・納品用READMEが入っています。
