# このフォルダで作業するときの約束事（Claude Code向け）

クラウドワークスで受注した案件の納品物を作るフォルダです。
依頼内容は `requirements.md` に書いてあります。必ず最初に読んでください。

## 作るもの
- `requirements.md` の要件どおりに動くPythonスクリプト（`main.py` を書きかえて使う）
- 日本語・初心者向けの `README.md`（`README.md` の ○○ や（ ）の部分をすべて埋める）
- `tests/` の pytest テスト。`python -m pytest` がすべて通ること

## コードのルール
- Python 3.10以上、Windowsで動くこと（パスは `pathlib` を使い、どこから実行しても動くようにする）
- ライブラリは必要なものだけ。追加したら `requirements.txt` にも書く
- コメントは日本語で、初心者が読んでも分かるように書く
- エラーはすべて日本語のメッセージで出す（`InputDataError` を使い、トレースバックを見せない）
  - ファイルがない／必要な列がない／空のファイル／出力ファイルをExcelで開いたまま、は必ず対応する
- CSVは UTF-8 と Shift_JIS（cp932）の両方を読めるようにする
- 元の入力ファイルは書き換えない。出力は `output/` に出す
- `.bat` ファイルは作らない（Windowsのセキュリティ機能で止められることがある）。実行方法は `python main.py` で案内する

## データの扱い
- 動作確認は `sample_data/` のダミーデータで行う。実在の人名・メールアドレス・電話番号は使わない
- クライアントの本番データは `client_data/` に置く想定（Gitには入れない）。このフォルダの中身は読まない
- 鍵ファイル（`credentials.json`、`.env`）は絶対にコミットしない

## スクレイピング案件の場合
- 対象サイトの利用規約と robots.txt を確認し、禁止されていれば作業を止めて報告する
- ログインが必要なページは扱わない
- アクセスの間に1秒以上の待ち時間を入れる
- テストは保存したHTMLで行い、本物のサイトにはアクセスしない

## 終わったら
- `python -m pytest` と `python main.py` を実行して、結果を報告する
- `requirements.md` の「確認事項」で決まっていないものがあれば、作業を止めずに仮の決め方を書いて報告する
