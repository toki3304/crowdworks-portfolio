## 実行方法

### 1. 準備（最初の1回だけ）

1. [Python公式サイト](https://www.python.org/downloads/) からPython 3.10以上をインストールします
   （Windowsではインストール画面の **「Add python.exe to PATH」にチェック** を入れてください）
2. このフォルダでコマンドプロンプト（Macはターミナル）を開き、必要なライブラリを入れます

```
pip install -r requirements.txt
```

> フォルダでコマンドプロンプトを開くには、エクスプローラーでこのフォルダを開き、
> 上のアドレスバーに `cmd` と入力して Enter を押します。

### 2. 実行

```
python main.py
```

`sample_data/` のファイルが処理され、`output/結果.xlsx` ができます。

ご自身のファイルを処理するときは、入力ファイルと出力ファイルを指定します。

```
python main.py 入力ファイル.xlsx 出力ファイル.xlsx
```

## よくあるエラー

| 表示されるメッセージ | 対処 |
|---|---|
| ファイルが見つかりません | ファイル名と置き場所を確認してください |
| 必要な列がありません | 1行目の列名が「入力の形式」と同じか確認してください |
| 出力ファイルに書き込めません | 出力ファイルをExcelで開いていたら閉じてから実行してください |
| `python` が見つからない | Pythonのインストール時に「Add python.exe to PATH」にチェックが入っていたか確認してください |
