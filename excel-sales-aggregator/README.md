# 売上Excel集計ツール

フォルダに入れた複数の売上ファイル（Excel / CSV）を自動で1つにまとめ、
**「月別×店舗別」** と **「商品別」** の集計表を1つのExcelファイルに出力するPythonツールです。

毎月、店舗ごとに届くExcelを手作業でコピー＆ペーストして集計している、という作業を自動化します。

## できること

- フォルダ内の `.xlsx` / `.xls` / `.csv` ファイルをまとめて読み込み
- 売上金額（数量 × 単価）を計算
- 3つのシートを持つExcelを出力
  - **月別×店舗別**：行が年月、列が店舗、合計つき
  - **商品別**：販売数量と売上金額を売上の多い順に表示
  - **明細**：全ファイルの明細を1つにまとめたもの（どのファイルから来たかも記録）
- よくある「汚いデータ」に対応
  - 全角数字（`１２`）やカンマ付きの数字（`1,200`）
  - 店舗名・商品名の前後の空白
  - 空欄など読み取れない行は除外し、何行除外したかを表示
  - Shift_JIS（Excelで保存したCSV）とUTF-8のどちらのCSVも読み込み
- エラーは日本語で表示（必要な列がない、ファイルがない、出力ファイルをExcelで開いたまま、など）

## 入力ファイルの形式

1行目に次の列名がある表を想定しています（列の順番は自由、ほかの列があっても問題ありません）。

| 日付 | 店舗 | 商品 | 数量 | 単価 |
|---|---|---|---|---|
| 2026-07-01 | 渋谷店 | コーヒー | 13 | 450 |
| 2026-07-01 | 渋谷店 | ケーキ | 8 | 550 |

`sample_data/` に、3店舗×3か月分（9ファイル）のダミーデータが入っています。

## 実行方法

### 1. 準備（最初の1回だけ）

1. [Python公式サイト](https://www.python.org/downloads/) からPython 3.10以上をインストールします
   （Windowsではインストール画面の **「Add python.exe to PATH」にチェック** を入れてください）
2. このフォルダでコマンドプロンプト（Macはターミナル）を開き、必要なライブラリを入れます

```
pip install -r requirements.txt
```

### 2. 実行

**Windows**：`run.bat` をダブルクリックするだけです。

**コマンドで実行する場合**：

```
python aggregate_sales.py
```

`sample_data/` が集計され、`output/売上集計.xlsx` ができます。

自分のファイルを集計したいときは、入力フォルダと出力ファイルを指定します。

```
python aggregate_sales.py 入力フォルダ 出力ファイル.xlsx
```

## テスト

```
python -m pytest
```

集計結果の正しさ、全角数字・空欄の扱い、エラー時の動作を確認するテストが入っています。

## ファイル構成

```
excel-sales-aggregator/
├── aggregate_sales.py    # 集計ツール本体
├── make_sample_data.py   # ダミーデータを作り直すスクリプト
├── run.bat               # Windows用：ダブルクリックで実行
├── requirements.txt      # 必要なライブラリ
├── sample_data/          # ダミーの売上データ（9ファイル）
└── tests/                # 自動テスト
```

## カスタマイズの例

ご依頼に合わせて、次のような変更が可能です。

- 列名や集計の切り口（担当者別、週別など）の変更
- グラフ付きのExcel出力
- 毎月決まったフォルダを自動で集計
- Pythonが入っていないPCでも動くexeファイル化

## 使用技術

Python 3 / pandas / openpyxl / pytest
